# Сервис для подключения к чату

## Как установить

Для установки потребуется пакетный менеджер **uv**

**Установить зависимости:**

`uv sync`

**Уставносить скрипты как отдельные команды из корня проекта:**

`uv pip install -e .`

**Проверить установку:**

`chat_connection --help`

## Использование CLI

Интерфейс командной строки (CLI) настроен с использованием `configargparse`, что позволяет задавать аргументы через флаги командной строки, переменные окружения или файл `config.yaml`. Ниже приведены доступные команды и их параметры.

Параметры передающиеся по умолчанию из конфигурационного файла:
- `host`: Хост сервера
- `read_port`: Порт для чтения чата
- `write_port`: Порт для написания в чат
- `history`: Файл для записи истории чата

Параметры которые могут быть заданы через интерфейс командрой строки или переменную окружения:
- `user_name`: Имя пользователя
- `user_token`: Токен авторизации пользователя

## Команды

- **view_chat**: Подключение к чат-серверу для просмотра сообщений.
  - `--host`, `--CHAT_HOST`: Хост сервера (по умолчанию: из `config.yaml`).
  - `--port`, `--CHAT_READ_PORT`: Порт для чтения сообщений (по умолчанию: из `config.yaml`).
  - `--history`, `--CHAT_HISTORY_FILE`: Файл для хранения истории сообщений (по умолчанию: из `config.yaml`).

- **connect_chat**: Подключение к чат-серверу для отправки сообщений.
  - `--host`, `--CHAT_HOST`: Хост сервера.
  - `--port`, `--CHAT_WRITE_PORT`: Порт для отправки сообщений.
  - `--user_token`, `--CHAT_USER_TOKEN`: Токен авторизации пользователя.
  - `--user_name`, `--CHAT_USER_NAME`: Имя пользователя для отправки сообщений.

- **send_message**: Отправка одного сообщения на чат-сервер.
  - `-m`, `--message`: Текст сообщения (обязательно).
  - `--host`, `--CHAT_HOST`: Хост сервера.
  - `--port`, `--CHAT_WRITE_PORT`: Порт для отправки сообщений.
  - `--user_token`, `--CHAT_USER_TOKEN`: Токен авторизации пользователя.
  - `--user_name`, `--CHAT_USER_NAME`: Имя пользователя для отправки сообщений.

- **register_user**: Регистрация нового пользователя на чат-сервере.
  - `--host`, `--CHAT_HOST`: Хост сервера.
  - `--port`, `--CHAT_WRITE_PORT`: Порт для отправки сообщений.
  - `--user_name`, `--CHAT_USER_NAME`: Имя пользователя для регистрации.

## Конфигурация
Уровень логирования и файл для хранения логов конфигурируются переменными окружения:
- **LOG_LEVEL**: например, `LOG_LEVEL=debug`.
- **LOG_FILE**: например, `LOG_FILE=chat_app.logs`.

Аргументы команд можно указать:
- **Флаги командной строки**: например, `--host 127.0.0.1`.
- **Переменные окружения**: например, `CHAT_HOST=127.0.0.1`.
- **Файл конфигурации**: Значения по умолчанию загружаются из `./config.yaml`.

Пример использования после установки скрипта:
```bash
view_chat

register_user --port=5050 --user_name=ivan_pupkin

send_message -m="Привет, мир!" --user_name=ivan_pupkin

connect_chat --user_token=8e8ea18e-7b81-11f0-a5a4-0242ac110003
